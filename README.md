# -Klasifikasi-Citra-Emosi-Wajah-Menggunakan-CNN
Project ini menggunakan metode Convolutional Neural Network (CNN) untuk mengklasifikasikan emosi manusia berdasarkan citra wajah. Proses meliputi preprocessing gambar, pelatihan model, dan evaluasi untuk menghasilkan sistem pengenalan emosi wajah berbasis Deep Learning.
